# H Karate v0.6.0 - Production Release

## What's New

### Core Features
- ✅ Professional license system with Ed25519 + AES-256 encryption
- ✅ 3 scoring modes: Kumite, Kata 1v1, Kata All-In tournaments
- ✅ Web judges via QR code (unlimited judges, no app install)
- ✅ OBS overlay for live streaming
- ✅ 6 languages: EN, AR (RTL), JA, FR, DE, ES

## Download

Choose one:
- **Installer** (Recommended): Creates desktop shortcut, adds to Start Menu
- **Portable**: No installation, run from USB drive

## System Requirements

- Windows 10 or 11 (64-bit)
- 4GB RAM minimum
- 200MB disk space
- Internet for license activation only

## Installation

1. Download the installer
2. Run and follow the setup wizard
3. Purchase a license at https://h-karate-app.web.app/#pricing
4. Drop your license file into the app
5. Start scoring!
